
# Sorting Algorithms Activity

## Introduction

Kini nga Java program nagpakita kung unsaon paggamit ang tulo ka sorting algorithms: Bubble Sort, Selection Sort, ug Insertion Sort.

Ang tumong sa program mao ang paghan-ay sa mga numero gikan sa pinakagamay hangtod sa pinakadako. Gigamit ang parehas nga original array ug naghimo og separate copy para sa matag sorting algorithm.

## 1. Bubble Sort

Ang Bubble Sort magkumpara sa duha ka magkatapad nga numero. Kung ang numero sa wala mas dako kaysa numero sa tuo, ilang ibaylo ang ilang pwesto.

Balik-balikon kini hangtod mahan-ay ang tanan nga numero. Sa matag pasada, ang pinakadako nga numero mobalhin padulong sa katapusan sa array.

## 2. Selection Sort

Ang Selection Sort mangita una sa pinakagamay nga numero sa wala pa mahan-ay nga parte sa array.

Human makit-an ang pinakagamay nga numero, ibalhin kini sa unang pwesto sa wala pa mahan-ay nga parte. Padayonon kini hangtod mahuman ang paghan-ay.

## 3. Insertion Sort

Ang Insertion Sort magsugod sa ikaduhang numero. Ikompara niini ang numero sa mga numero nga naa sa wala nga bahin.

Kung mas gamay ang numero, ibalhin ang mas dagkong numero sa tuo aron makahatag og lugar. Dayon ibutang ang numero sa hustong pwesto.

Padayonon kini hangtod mahan-ay ang tibuok array.

## Differences Between the Three Algorithms

- **Bubble Sort:** Magkumpara sa magkatapad nga numero ug magbaylo sa ilang pwesto.
- **Selection Sort:** Mangita sa pinakagamay nga numero ug ibutang kini sa hustong pwesto.
- **Insertion Sort:** Magkuha og usa ka numero ug isulod kini sa sakto nga lugar taliwala sa mga numero nga nahapsay na.

Parehas silang makahan-ay sa mga numero, apan lahi-lahi ang ilang proseso.

## Reflection Questions

### 1. How does each sorting algorithm arrange numbers? What makes their processes different?

Ang Bubble Sort magkumpara sa magkatapad nga numero ug magbaylo kung dili sakto ang ilang pagkahan-ay. Ang Selection Sort mangita sa pinakagamay nga numero ug ibutang kini sa unahan. Ang Insertion Sort magkuha og numero ug ibutang kini sa hustong pwesto taliwala sa mga numero nga nahapsay na. Lahi sila tungod kay lahi-lahi ang ilang paagi sa paghan-ay.

### 2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

Para nako, ang Bubble Sort ang pinakasayon sabton ug buhaton. Simple ra ang proseso niini kay magkumpara lang sa duha ka magkatapad nga numero ug magbaylo sa ilang pwesto kung kinahanglan. Sayon ra sab masabtan ang code bisan nagsugod pa lang ko sa pagtuon og programming.

### 3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Para nako, ang Insertion Sort ang mas maayo kung daan nang nahapsay ang mga numero. Dili na kinahanglan ibalhin ang mga numero kay naa na sila sa sakto nga pwesto. Usa ra ka comparison ang kinahanglan sa matag numero, busa mas gamay ang trabaho nga buhaton niini.

### 4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung magdugang ko og daghang numero sa array, mas dugay ang pag-sort tungod kay mas daghan na ang kinahanglan ikumpara ug han-ay. Ang Bubble Sort ug Selection Sort mahimong hinay kung daghan na kaayo ang numero. Ang Insertion Sort maayo kung hapit na mahan-ay ang mga numero, pero mahimo sab kining mohinay kung daghan ang mga numero nga nagkalain-lain ang pwesto.

### 5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

Importante nga makat-on ko og lain-laing sorting algorithms kay dili parehas ang sitwasyon sa matag programming problem. Adunay algorithm nga mas angay kung gamay ra ang data, ug adunay mas maayo kung hapit na mahan-ay ang mga numero. Kung kasabot ko sa ilang kalainan, makapili ko sa mas angay ug mas epektibo nga pamaagi sa paghimo og program.

## Conclusion

Pinaagi niini nga activity, nakat-on ko nga adunay lain-laing pamaagi sa paghan-ay sa mga numero. Bisan parehas ang resulta sa Bubble Sort, Selection Sort, ug Insertion Sort, lahi-lahi ang ilang proseso. Importante nga masabtan ang matag algorithm aron makahimo og mas maayong desisyon isip usa ka future programmer.
